# Tetris MVP 구현 To-Do

[PRD.md](./PRD.md)를 기준으로 작성한 실행 계획이다. 아래 순서대로 진행하며 각 작업의 완료기준을 검증한 뒤 체크한다. Task에 표시한 의존 작업이 완료되면 해당 기능을 독립적으로 구현하고 테스트할 수 있다.

## 실행 및 테스트

`index.html`을 더블클릭하면 브라우저에서 바로 게임이 시작된다. 프레임워크, 빌드 도구, 개발 서버, 로그인은 필요하지 않다.

조작: ← / → 이동, ↑ 시계 방향 회전, ↓ Soft Drop, Space Hard Drop. 오른쪽의 **다시시작** 버튼은 보드와 점수를 초기화한다.

게임 규칙 자동 테스트는 Node.js가 설치된 개발 환경에서 `node --test tests/game.test.cjs`로 실행한다. Node.js는 게임 플레이에 필요하지 않다. 자동 테스트 13개와 Chrome의 로컬 파일 실행·키보드 조작·4줄 800점·게임 오버·재시작 검증을 통과했다. Edge·Firefox의 실제 플레이 검증은 아직 수행하지 않았다.

## 구현 기본안

PRD에 구체적으로 정해지지 않은 사항은 다음 기본안으로 구현한다.

- HTML, CSS, JavaScript로 구성하고 게임 로직, 화면 렌더링, 입력·시간 처리를 분리한다. 개발 및 테스트 도구는 무료 도구를 사용한다.
- 페이지를 열면 게임을 자동 시작한다. 보드는 가로 10칸 × 세로 20칸이다.
- ← / →: 좌우 이동, ↑: 시계 방향 90도 회전, ↓: Soft Drop, Space: 즉시 바닥까지 하강하고 고정하는 Hard Drop. 회전 결과가 충돌하면 원래 상태를 유지한다.
- 자동 하강은 0.5초에 한 칸, Soft Drop은 키를 누를 때 즉시 한 칸 하강하고 누르는 동안 50ms 간격으로 반복한다.
- 매 생성 시 I, O, T, S, Z, J, L 중 하나를 무작위로 선택한다. 테스트에서는 난수와 시간을 제어한다.
- 동시에 1 / 2 / 3 / 4줄을 제거하면 각각 100 / 300 / 500 / 800점을 얻는다. 줄 제거가 없으면 점수가 유지된다.
- 새 블록이 보드 상단 중앙에 생성될 공간이 없으면 Game Over로 판정한다.

## MVP 범위

로그인, 온라인 멀티플레이, 랭킹 서버, 아이템, Hold, Ghost Piece, 모바일 터치 컨트롤, 사운드 효과는 PRD에 따라 이번 작업 범위에서 제외한다. 외부 유료 서비스에 의존하지 않는다.
