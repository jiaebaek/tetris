# 게임 로직 점검

## 점검 절차

PRD.md와 README.md에서 보드 크기·회전·생성·종료 규칙을 확인한다. 로직과 기존 테스트를 읽고 제어된 보드·블록·난수로 아래 사례를 실행한다. 코드나 테스트 파일을 직접 수정하지 않는다. 필요하면 파일을 남기지 않는 재현 실험을 수행한다. 실행하지 못한 항목은 미검증으로 보고한다.

## 점검 체크리스트

- [ ] 보드 경계: x=0·9, y=0·19 및 경계 밖의 점유 칸을 검사한다.
  - 통과: 모든 점유 칸이 경계 안에 있을 때만 위치를 허용한다 / 실패: 경계 밖을 허용하거나 유효한 가장자리 위치를 거부한다.
- [ ] 고정 블록 충돌: 빈 칸과 한 칸 이상 겹치는 위치를 비교한다.
  - 통과: 빈 공간은 허용하고 점유 칸 겹침은 거부한다 / 실패: 겹침을 놓치거나 형태 배열의 빈 칸까지 충돌로 처리한다.
- [ ] 거부된 이동: 벽·바닥·고정 블록 방향으로 이동한다.
  - 통과: 거부 후 좌표·형태·보드가 이전 상태와 같다 / 실패: 일부 좌표나 보드가 변경된다.
- [ ] 회전 불변식: 7종에 대해 회전과 반복 회전을 검사한다.
  - 통과: 점유 칸 수가 4개이며 4회 회전 후 원래 형태이고 O의 점유 위치가 유지된다 / 실패: 칸이 유실·추가되거나 원래 형태로 돌아오지 않는다.
- [ ] 회전 충돌: 벽·바닥·고정 블록 옆에서 회전한다.
  - 통과: 유효한 회전은 적용하고 충돌 회전은 형태·위치를 보존하며 거부한다 / 실패: 충돌을 허용하거나 거부 과정에서 상태가 일부 바뀐다.
- [ ] 고정과 후속 처리: 막힌 하강 및 다음 블록 생성까지 추적한다.
  - 통과: 현재 위치에 한 번 고정하고 기존 칸을 덮어쓰지 않으며 다음 블록은 줄 제거 후 생성한다 / 실패: 중복 고정·덮어쓰기·잘못된 생성 순서가 있다.
- [ ] 줄 제거 경계: 0~4줄과 떨어진 위치의 완성 줄을 검사한다.
  - 통과: 완성 줄만 제거하고 남은 행 순서 및 20행을 유지한다 / 실패: 인접 줄을 건너뛰거나 미완성 줄을 지우거나 보드 크기가 바뀐다.
- [ ] 생성과 종료: 상단 생성 공간이 비거나 막힌 상태를 비교한다.
  - 통과: 빈 공간에는 생성하고 막히면 종료하며 종료 이후 상태 변경을 막는다 / 실패: 블록을 겹쳐 생성하거나 종료 이후 게임 상태가 변한다.

## 보고

판정별로 사용한 보드·블록·좌표, 기대값과 실제값을 남긴다. 높음은 경계 침범·상태 손상·게임 진행 불가, 중간은 특정 조건의 이동·회전·라인 오류, 낮음은 결함을 숨기는 테스트·명명 문제다. 문제없으면 발견된 문제 없음을 명시한다.

|---|---|---|
| 함수 또는 파일:줄과 최소 재현 조건 | 높음·중간·낮음 중 하나 | 수정해야 할 판정과 회귀 테스트 사례 |
