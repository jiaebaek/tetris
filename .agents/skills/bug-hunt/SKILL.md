# 고위험 버그 탐색

## 점검 절차

PRD.md·README.md와 변경 내용을 읽고 상태·이벤트·타이머의 수명을 추적한다. 기존 테스트와 격리된 재현 실험을 사용한다. 코드를 직접 수정하지 않는다. 추정 문제는 확인된 버그와 구분하고 재현하지 못한 주장을 확정하지 않는다. 실행 불가 검사는 미검증으로 표시한다.

## 점검 체크리스트

- [ ] 상태 공유: 새 보드·블록·Restart 상태를 각각 생성하고 한 인스턴스를 변경한다.
  - 통과: 행·형태 원본·다른 게임 상태가 영향을 받지 않는다 / 실패: 얕은 복사나 공유 참조로 다른 상태가 오염된다.
- [ ] 타이머 중복: 반복 Restart 및 종료 후 재시작을 수행한다.
  - 통과: 활성 자동 하강 루프가 하나이고 이전 콜백이 새 게임을 변경하지 않는다 / 실패: 속도 증가·중복 고정·이전 게임 콜백 반영이 발생한다.
- [ ] 입력 수명: 키 유지·해제·포커스 상실·종료·Restart를 조합한다.
  - 통과: 반복 입력과 리스너가 정리되고 종료 후 입력이 상태를 바꾸지 않는다 / 실패: 붙잡힌 키 상태나 누적 리스너로 의도하지 않은 조작이 발생한다.
- [ ] 동시 하강 요청: 자동 하강과 Soft Drop이 같은 시점에 도착하는 조건을 재현한다.
  - 통과: 각 요청이 최신 상태에서 처리되고 하나의 블록 고정·점수 반영이 중복되지 않는다 / 실패: 오래된 블록을 고정하거나 점수·생성이 중복된다.
- [ ] 줄 제거와 생성 순서: 여러 줄 완성과 상단 생성 충돌을 조합한다.
  - 통과: 줄 제거·점수 반영 후 새 보드로 생성 및 종료를 판단한다 / 실패: 줄을 건너뛰거나 제거 전 보드 때문에 잘못 종료한다.
- [ ] 프레임 지연: 긴 시간 경과와 비활성 창 복귀를 제어된 시간으로 검사한다.
  - 통과: 문서화된 시간 정책대로 처리하고 무한 반복·멈춤·폭발적 연속 처리가 없다 / 실패: 복귀 시 게임이 멈추거나 제어 불가능한 처리가 발생한다.
- [ ] 오류와 경계: 7종의 가장자리 이동·회전·생성 및 반복 렌더링을 실행한다.
  - 통과: 예외·보드 크기 변경·DOM 누적·리소스 누수가 없다 / 실패: 재현 가능한 예외나 상태·화면 손상이 있다.

## 보고

높음은 게임 중단·보드 손상·중복 루프, 중간은 특정 입력·시간 조건의 기능 오류, 낮음은 영향이 작은 표시·관측 문제다. 심각도 내에서는 재현 빈도와 영향 범위가 큰 문제를 먼저 배치한다. 각 항목에 파일·줄, 최소 재현, 기대값·실제값, 확인 여부를 적는다. 미확인 가설에는 확인 방법을 적고 문제없으면 발견된 문제 없음을 명시한다.

| 항목 | 심각도(높음·중간·낮음) | 개선안 |
|---|---|---|
| 우선순위와 버그 근거 또는 미확인 가설 | 높음·중간·낮음 중 하나 | 최소 수정 방향 및 재현·회귀 검증 방법 |
