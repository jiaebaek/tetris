# 플레이 시나리오 QA

## 점검 절차

PRD.md와 README.md의 실행법·조작키·점수 규칙을 읽고 게임을 실행한다. 브라우저와 실행 명령을 기록한다. 난수에 기대어 줄 완성을 기다리지 말고 기존 테스트 도구 또는 격리된 세션의 상태 설정으로 재현 가능한 보드와 블록을 준비한다. 테스트용 상태 설정은 저장되는 소스 변경과 구분한다. 코드를 직접 고치지 않는다.

각 시나리오의 준비 상태 → 행동 → 기대값 → 실제값을 기록한다. 브라우저를 사용할 수 없으면 자동 테스트 결과와 실제 플레이 미검증을 구분한다. 아래 점수는 현재 README 기본안이며 사용자에게 승인된 규칙이 바뀌면 최신 규칙을 적용하고 차이를 기록한다.

## 점검 체크리스트

- [ ] 첫 접속: 페이지를 새로 연다.
  - 통과: 설치·로그인 없이 10 × 20 보드·0점·첫 블록이 보이고 자동 하강한다 / 실패: 시작되지 않거나 초기 상태가 다르다.
- [ ] 좌우 이동과 회전: 빈 공간과 벽·고정 블록 옆에서 조작한다.
  - 통과: 키 입력에 화면이 반응하고 충돌 동작은 이전 상태를 유지한다 / 실패: 조작이 누락되거나 보드 밖·겹침 위치로 이동한다.
- [ ] 자동 하강과 고정: 아래가 빈 블록 및 바닥 직전 블록을 관찰한다.
  - 통과: 기본 1초 간격으로 하강하고 막히면 현재 위치에 고정 후 새 블록이 나온다 / 실패: 하강·고정·다음 블록 중 하나가 누락되거나 중복된다.
- [ ] Soft Drop: ↓를 누르고 유지한 뒤 놓고, 다시 누른 상태에서 창 포커스를 옮긴다.
  - 통과: 즉시 한 칸 및 기본 50ms 간격 하강 후 키 해제·포커스 상실 시 반복이 멈춘다 / 실패: 반응이 없거나 반복이 남거나 충돌을 통과한다.
- [ ] 1·2·3줄 점수: 각각 완성 직전 보드에서 마지막 블록을 고정한다.
  - 통과: 해당 줄만 사라지고 점수가 각각 100·300·500점 증가한다 / 실패: 제거 줄 수 또는 증가량이 다르다.
- [ ] 4줄 점수: 하단 네 줄에 같은 열 하나만 비우고 세로 I 블록으로 채운다.
  - 통과: 네 줄이 함께 제거되고 기존 점수에서 정확히 800점 증가한다 / 실패: 네 줄 일부가 남거나 점수 증가량이 다르다.
- [ ] 점수 누적: 줄 없는 고정 후 1줄 제거와 4줄 제거를 연속 수행한다.
  - 통과: 줄 없는 고정에는 점수가 유지되고 이후 총 900점 증가한다 / 실패: 고정만으로 점수가 증가하거나 누적이 잘못된다.
- [ ] Game Over: 다음 블록의 상단 생성 공간을 막는다.
  - 통과: 종료 안내가 표시되고 자동 하강·키 조작으로 상태가 바뀌지 않는다 / 실패: 종료하지 않거나 종료 후 계속 진행한다.
- [ ] 종료 후 Restart: Game Over 화면에서 Restart를 누른다.
  - 통과: 빈 보드·0점·새 블록으로 초기화되고 종료 안내가 사라지며 자동 하강한다 / 실패: 이전 상태가 남거나 게임이 다시 시작되지 않는다.
- [ ] 진행 중 반복 Restart: 플레이 중 버튼을 여러 번 누른다.
  - 통과: 매번 초기화되고 루프·입력 중복 없이 기본 속도로 진행한다 / 실패: 하강 속도가 증가하거나 입력이 중복된다.

## 보고

시나리오별 통과·실패·미검증 및 재현 기록을 제시한다. 높음은 시작·종료·재시작 불능, 중간은 조작·줄 제거·점수 오류, 낮음은 안내·표시 문제다. 문제없으면 발견된 문제 없음을 명시한다.

|---|---|---|
